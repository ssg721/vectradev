# vectradev

Free photo tools that run entirely in the browser. Images are processed on the user's device and never uploaded.

Live at [vectradev.in](https://vectradev.in).

## Features

- **Compress to any KB:** produces a JPG under a size limit at the best quality that fits, with an optional minimum size.
- **Exam photo and signature resizer:** presets for IBPS, SBI, SSC, RRB, UPSC, NEET UG and JEE Main. Each document (photo, signature, thumb impression, handwritten declaration) is set to the required pixels, KB range and DPI, and checked against those rules.
  - Photos: drag-to-position crop with a face guide, and an optional name-and-date strip.
  - Signatures, thumb impressions and declarations: the paper is whitened and the empty margins are trimmed before fitting.
  - A custom override for when a notification's rules differ from the preset.
- **Image resizer:** exact pixels, centimetres or inches with DPI; crop to fill or fit with margins; optional KB limit.
- **Image converter:** JPG, PNG and WebP output from JPG, PNG, WebP, GIF, BMP, AVIF and iPhone HEIC input. Several files at once, with ZIP download.

## How it works

- Pages are static HTML generated by [Astro](https://astro.build). Each tool is a small [Preact](https://preactjs.com) island, so only the interactive part loads JavaScript.
- Encoding runs in a Web Worker using MozJPEG and libwebp compiled to WebAssembly ([jSquash](https://github.com/jamsinclair/jSquash)), so the page stays responsive on phones.
- HEIC decoding ([heic2any](https://github.com/alexcorvi/heic2any)) is loaded only when a HEIC file is opened.
- Styling uses [Tailwind CSS](https://tailwindcss.com) with the [Atkinson Hyperlegible Next](https://www.brailleinstitute.org/freefont/) typeface, self-hosted.

### Size targeting

`src/lib/compress.ts` searches JPEG quality (and, when allowed, pixel size) to land inside an allowed range:

- Upper limits are checked with 1 KB = 1000 bytes and lower limits with 1 KB = 1024 bytes, so a file passes whichever way a portal counts.
- It aims for the middle of a range, and at least 10% above any minimum.
- When resizing is allowed, it adjusts the pixel size to keep quality in a good band rather than producing a tiny high-quality image or a large blocky one.
- If a clean image is still below a minimum (common for small signatures), it inserts a JPEG comment segment. The picture is unchanged and viewers ignore it.
- DPI is written into the JFIF header (`src/lib/jpeg-meta.ts`).

### Exam presets

Each exam is one JSON file in `src/data/exams/`, validated at build time against the schema in `src/content.config.ts`. Invalid values, such as `"20kb"` instead of `20` or a minimum above the maximum, fail the build.

```jsonc
{
  "id": "signature", "label": "Signature", "kind": "signature",
  "width": 140, "height": 60, "dpi": 200,   // exact pixel size
  "minKb": 10, "maxKb": 20,                 // allowed file size range
  "fit": "contain"                          // "cover" = crop (photos), "contain" = trim and fit (signatures, thumbs)
}
```

- `"liveCapture": true` marks documents the portal captures with the camera, so no upload tool is shown.
- `"sizeIsSuggested": true` marks a pixel size that is a sensible default rather than a rule from the notification.
- Each exam records `lastVerified` and a `source`, which are shown on its page.

Adding a file generates the exam's page, its row in the exam hub, footer links and sitemap entry.

## Development

Requires Node.js 22.23.4 or newer (see `.nvmrc`).

```bash
npm install
npm run dev        # http://localhost:4321
npm test           # engine unit tests
npm run check      # type check
npm run build      # static site in dist/
npm run preview    # serve dist/ locally
```

### Optional configuration

Environment variables (see `.env.example`). When unset, the related feature is off.

| Variable | Purpose |
|---|---|
| `PUBLIC_CF_ANALYTICS_TOKEN` | Cloudflare Web Analytics (cookie-free) |
| `PUBLIC_ADSENSE_CLIENT` | AdSense publisher ID |
| `PUBLIC_ADSENSE_SLOT` | AdSense display ad slot. Ads appear only between page sections, never next to upload or download buttons. |

## Project layout

```
src/
  data/exams/*.json        exam presets, one per exam
  content.config.ts        preset schema, checked at build time
  lib/                     size search, JPEG metadata, codec worker, rendering, image loading
  components/tools/        interactive tools (Preact)
  layouts/                 page frames
  pages/                   routes; [conversion].astro and compress-image-to-[size].astro each generate several pages
public/                    icons, share image, robots.txt, security headers
```
